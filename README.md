# 🌍 Air Pollution Data Analysis

## 📌 Project Overview
This project focuses on analyzing air pollution data to identify trends and patterns in environmental pollutants using Python.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## 📂 Project Structure
- data/ → Contains dataset (Excel file)
- notebook/ → Contains Jupyter/Colab notebook
- images/ → Visualization outputs (optional)

## 📊 Key Features
- Data cleaning and preprocessing
- Analysis of pollutants (CO, Ozone, PM10, PM2.5)
- Data visualization using graphs and charts

## 🚀 Outcome
This project helped in understanding real-world data analysis, visualization, and environmental data insights.

## ▶️ How to Run
1. Open the notebook in Google Colab or Jupyter
2. Upload dataset if required
3. Run all cells

## 📎 Dataset
Dataset is included in the `data` folder
